# Chi Zhang’s academic desktop

Updated scope · 13 November 2026

## Visitor experience

A prospective advisor should be able to identify Chi Zhang, understand his research interests, and reach a project or contact link within a few actions. Present the portfolio in English. On entry, open **About Me.doc** beside the desktop shortcuts, with a fixed taskbar below. On a phone, show the introduction in one readable pane with Start always within reach.

The four candidate research directions are angle-based target tracking and control, information-theoretic sensor placement, multi-robot relative localization and formation control, and formal verification and AI agents for control theory.

## Appearance and controls

- Use Luna Blue gradient title bars, distinct active and inactive borders, original yellow folders, and a green Start button. An original landscape can suggest the XP era. Use locally available system fonts and record the source and license of each third-party asset.
- Keep the first document compact enough to expose the desktop icons. Give the biography the largest text area. Use clear headings and comfortable line lengths. Give folder windows large labeled icons or thumbnails.
- A mouse click selects a desktop or folder icon. Double-click opens it. Clicking the wallpaper clears selection. A touch tap, Enter, or Space opens the focused item. Start shortcuts and taskbar buttons activate with a single click.
- Open, focus, drag, resize, maximize, minimize, restore, and close all managed windows consistently. Selecting an open item restores or focuses its existing window. Its taskbar button shows the active state. Keep title bars and buttons reachable after a drag, zoom, or viewport resize.
- On narrow screens, show one foreground window with scrolling content. Start and the taskbar keep navigation accessible. Closing or minimizing returns to the previous visible window or the desktop. Use labeled buttons, visible focus, generous touch targets, and reduced-motion support.

## Review criteria

1. On a laptop, a first-time visitor sees the identity, the desktop entries, and the taskbar together. At phone width, the visitor can read the same content and operate every section with single taps.
2. Open Projects twice, switch to About, minimize it, restore it from the taskbar, and close it. Each step produces one predictable active window. Repeat with keyboard controls.
3. Open a project and return to its folder. With supplied media or temporary fixtures, browse thumbnail to full image and back. Verify every available contact and CV link. Missing content has an honest, readable state.
4. Add a project, several photos, and a temporary folder using existing viewers. Verify that the window manager and viewers need no edits for these additions.
5. A reproducible build produces static files for the existing GitHub Pages root. Review the local production build, documentation, and workflow before approving publication.

## Scope

The desktop includes a local biography editor, date and time preferences, and a media player with shared notification-area controls. Excluded features include boot and login screens, games, simulated errors, general-purpose file editing, public uploads, accounts, messaging, a backend, a database, and a CMS. Custom-domain setup is a future hosting decision. The desktop metaphor takes conceptual inspiration from [Vanessa Li’s portfolio](https://vanessa-li.com/).
